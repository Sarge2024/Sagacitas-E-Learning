# Confirmar registro e fechar popup ao cadastrar usuário

## Objetivo
Após salvar um novo usuário, exibir uma mensagem de confirmação clara e fechar o popup de cadastro automaticamente em ambos os fluxos (admin e público).

## Fluxo 1: Cadastro Administrativo (`UserAccessManagementView.tsx`)

**Arquivo:** `src/components/expert/UserAccessManagementView.tsx`

**Estado atual (linhas 186-231):** Ao criar/editar usuário, o toast aparece por 3 segundos e o modal fecha imediatamente (`setIsModalOpen(false)` na linha 231). O toast e o fechamento do modal acontecem simultaneamente, o que pode fazer o usuário não perceber a confirmação.

**Alterações necessárias:**
1. Ao criar um novo usuário (modo create, linhas 219-228), **não fechar o modal imediatamente**. Em vez disso:
   - Exibir uma tela de sucesso dentro do modal com ícone `CheckCircle2`, nome do usuário criado e cargo atribuído
   - Após 2 segundos, fechar o modal automaticamente e selecionar o novo usuário na lista
2. Ao editar um usuário existente (modo edit, linhas 164-185), manter o comportamento atual (toast + fechar modal), pois a edição não precisa de tanta ênfase

**Implementação:**
- Adicionar state `justCreated: boolean` (ou usar `successView` como em `SlideQuestionModal.tsx`)
- Quando `handleCreateOrUpdateUser` termina com sucesso no modo create:
  - Setar `isSaving = false`
  - Em vez de `setIsModalOpen(false)`, exibir tela de confirmação dentro do modal
  - Usar `setTimeout` de ~2.5s para fechar o modal automaticamente
- O modal continua renderizado, mas com conteúdo diferente (tela de sucesso) até fechar

**Código aproximado (tela de sucesso dentro do modal existente):**
```tsx
{/* Tela de sucesso após criação */}
{justCreated && (
  <div className="text-center py-6 space-y-3">
    <CheckCircle2 className="w-12 h-12 text-emerald-500 mx-auto" />
    <h3 className="text-sm font-black text-slate-900">Usuário Cadastrado!</h3>
    <p className="text-xs text-slate-600">
      <strong>{formName}</strong> foi criado com perfil <strong>{formRole}</strong>.
    </p>
    <p className="text-[10px] text-slate-400">Esta janela fechará automaticamente...</p>
  </div>
)}
```

## Fluxo 2: Cadastro Público (`LoginPortal.tsx`)

**Arquivo:** `src/components/LoginPortal.tsx`

**Estado atual (linhas 166-241):** O `handleRegister` cria o usuário no Firebase Auth + Firestore e chama `onLoginSuccess` (linha 230), que faz o App.tsx renderizar a tela principal. Não há popup separado — o LoginPortal inteiro desaparece.

**Alteração necessária:**
1. Após `createUserWithEmailAndPassword` e `setDoc` com sucesso, exibir uma tela de confirmação dentro do card de registro antes de chamar `onLoginSuccess`
2. Usar o state `successMsg` (já existe na linha 110) para exibir "Conta criada com sucesso!" com ícone verde
3. Após ~1.5 segundos, chamar `onLoginSuccess` para entrar no app

**Implementação:**
- No `handleRegister`, após o Firestore write (linha 227):
  - Setar `successMsg('Conta criada com sucesso! Bem-vindo!')`
  - Usar `setTimeout` de 1.5s para chamar `onLoginSuccess`
  - NÃO chamar `onLoginSuccess` imediatamente — dar tempo do usuário ver a mensagem
- O componente `LoginPortal` já renderiza `successMsg` na linha 643-648, então a mensagem aparece automaticamente

## Verificação

1. Criar um novo usuário pelo painel admin → modal deve mostrar tela de sucesso por ~2s e fechar sozinho
2. Editar um usuário existente → deve funcionar como antes (toast + fechar)
3. Registrar-se pela tela de login → deve mostrar "Conta criada!" antes de entrar no app
4. Testar cenário de erro (email duplicado, senha fraca) → deve mostrar erro normalmente, sem comportamento regressivo
